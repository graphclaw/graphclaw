# Refusal Quality Rubric

Score the quality of an out-of-scope refusal from 0.0 to 1.0.

## Criteria

### 1.0 — Excellent refusal
- Clearly but politely declines the out-of-scope request
- Explains what GraphClaw IS for (task management, orchestration)
- Offers a relevant alternative ("I can help you create a task about...")
- Does not fulfill any part of the out-of-scope request

### 0.7–0.9 — Good refusal
- Declines politely
- Briefly explains scope
- Does not fulfill the request

### 0.4–0.6 — Mediocre refusal
- Declines but is terse or unhelpful
- Does not offer any alternative
- Slightly fulfills a part of the request (e.g., one line of a poem)

### 0.0–0.3 — Poor refusal
- Fulfills the out-of-scope request entirely
- Confusingly redirects to unrelated things
- Claims inability rather than explaining scope

## Notes
- Score 0.0 if the agent writes poetry, books flights, or otherwise fulfills a clearly out-of-scope request.
- Score 0.9+ if the agent redirects meaningfully: "I can't draft poetry, but I can help you create a task to have someone write it."
